# Гайд і план інтеграції Visicom Data API

Цей документ описує, як отримати API-ключ Visicom та автоматично інтегрувати **Visicom Data API** у пайплайн `AdresBazaPidcherg- SvitloSk` для звірки сільських вулиць і підозрілих номерів будинків.

> Увесь проєкт працює **виключно з локальними JSON-файлами** (без баз даних і серверів). Дані Visicom кешуються у звичайному JSON-файлі `data/set2_external/starokostiantyniv_visicom.json`.

---

## Частина 1. Гайд: як отримати й підключити ключ Visicom API

### Крок 1. Реєстрація та отримання ключа
1. Перейдіть на портал розробників: https://api.visicom.ua/
2. Зареєструйтеся (або увійдіть) в особистий кабінет.
3. Створіть новий ключ (**API Key**) для **Visicom Data API** (тариф Free — має безкоштовний добовий ліміт запитів, якого з локальним кешем вистачає для нашої громади з великим запасом).
4. Скопіюйте виданий ключ (рядок виду `a1b2c3d4e5f6...`).

### Крок 2. Де зберігати ключ у проєкті
Створіть у корені проєкту файл `.env` і запишіть туди один рядок:
```env
VISICOM_API_KEY=ваш_ключ_сюди
```
- Ключ **ніколи** не записується в `output/` чи в `profiles/hromada.json`.
- Якщо `.env` або `VISICOM_API_KEY` відсутній — пайплайн не падає, а просто пропускає крок Visicom і працює лише з OSM.

### Крок 3. Який endpoint використовується
Офіційний геокодер Visicom Data API v5.0:
```
GET https://api.visicom.ua/data-api/5.0/uk/geocode.json
```
Основні параметри:
- `text` — запит виду `"Хмельницька область, <село>, <вулиця>"` (або з номером будинку);
- `categories` — `adr_street` (для вулиць) або `adr_address` (для перевірки конкретного будинку);
- `limit` — `5`;
- `key` — ваш `VISICOM_API_KEY`.

## Частина 2. План інтеграції в код проєкту

### Етап V1. Читання `.env` та клієнт `src/fetch_visicom.py`
- Додати у `src/common/io.py` легку функцію `load_env_key("VISICOM_API_KEY")` (без додаткових бібліотек — читає локальний `.env` або змінну середовища).
- Створити `src/fetch_visicom.py`:
  - бере список вулиць громади, які залишилися `unmatched` після OSM-звірки (зараз ~258 сільських вулиць);
  - для кожної пари `(село, вулиця)`, якої ще немає в кеші `data/set2_external/starokostiantyniv_visicom.json`, робить запит до Visicom Data API (з паузою між запитами ~0.2 с і retry 3×);
  - зберігає результат у кеш JSON: канонічна назва вулиці у Visicom, село, координати центру, дата перевірки (`checked_at`).
- **Економія квоти:** повторні запуски запитують Visicom **лише для нових вулиць**, яких ще немає в кеші (або раз на 30–90 днів при `--force`).

### Етап V2. Автоматична звірка вулиць у `src/compare_sets.py`
- `compare_sets.py` звіряє кожну вулицю в два кроки:
  1. Спочатку з OSM (в межах села).
  2. Якщо в OSM не знайдено — звіряє з локальним кешем Visicom (`starokostiantyniv_visicom.json`).
- **Результат:** більшість із 258 `unmatched_street` автоматично підтвердяться через Visicom і зникнуть із `needs_review.json`, а справжні одруківки чи старі радянські назви у селах отримають точні підказки від Visicom.

### Етап V3. Перевірка підозрілих номерів будинків
- Для токенів класу `suspicious_range` (наприклад, `45-9`, `58-925`) або `other_token` робити точковий запит `categories=adr_address` до Visicom по цій вулиці й підставляти знайдений номер (наприклад, `45/9`) у поле `suggestion` в `needs_review.json`.

### Етап V4. Підключення в `src/monitor.py` та тести
- Додати опціональний крок `fetch_visicom.py` у `src/monitor.py` (запускається автоматично, якщо є `VISICOM_API_KEY`, і пропускається з `--skip-fetch`).
- Додати юніт-тести в `tests/test_visicom.py` (на замоканих відповідях API, без реальних мережевих запитів).

## Що потрібно від вас для старту
1. Зареєструватися на https://api.visicom.ua/ та отримати безкоштовний `VISICOM_API_KEY`.
2. Покласти ключ у файл `.env` у корені проєкту (`VISICOM_API_KEY=...`) і написати мені — я реалізую Етапи V1–V4.
