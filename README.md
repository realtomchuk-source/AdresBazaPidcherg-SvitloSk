# AdresBazaPidcherg — SvitloSk

Єдиний механізм та еталонна база адрес Старокостянтинівської громади Хмельницької області для визначення підчерг відключень електроенергії в новій версії додатку **SvitloSk**.

---

## 🎯 Мета проекту

Створити надійну, структуровану та верифіковану **статичну еталонну базу адрес** Старокостянтинівської громади з прив'язкою до підчерг (1.1 – 6.2), яка:
1. Слугуватиме єдиним джерелом правди для пошуку підчерг у додатку **SvitloSk** (3-тя сторінка та вибір підчерги).
2. Забезпечить чисті, нормалізовані назви населених пунктів, вулиць та номерів будинків без друкарських помилок і дублікатів.
3. Підтримуватиме періодичну звірку з першоджерелом (XLSX-переліки АТ «Хмельницькобленерго», PDF лише дублює їх) та керування активністю окремих записів.

---

## 📍 Межі проекту

- **Цільова база (продукт):** Старокостянтинівська міська територіальна громада (адмінцентр м. Старокостянтинів та 22 старостинські округи / села громади).
- **Універсальність механізму:** Інструментарій збору та звірки (з сайту АТ «Хмельницькобленерго» та відкритих джерел) проєктується як **параметризований** — за потреби йому можна задати профіль будь-якої іншої громади Хмельницької області.
- **Поза межами проекту:**
  - Розділення фронтенду та бекенду самого додатку `SvitloSk`.
  - Парсинг і розпізнавання довільного тексту з біжучої стрічки (планові/аварійні відключення) чи публікація в соцмережі (`svitlosk-publisher`).

## 📚 Опора на існуючі напрацювання (для вивчення)

Проект не починається з нуля — він систематизує та стандартизує результати попередніх розробок:
- **`підчерга` (`hromadas/starokostiantyniv`)** — існуюча база адрес (~2748 записів), екстрактори PDF/Excel, контекст громади та звіти про перейменовані вулиці.
- **`Baza`** — попередні парсери та процесори адрес.
- **`SvitloSk`** — поточний споживач даних (зокрема, логіка 3-ї сторінки та таблиці/міграції).
- **`Parser-SvitloSk 2`** — орієнтир щодо принципу незалежності збирачів даних та версіонованих JSON-наборів.

## 📋 Базові принципи

1. **Першоджерело:** Офіційні дані АТ «Хмельницькобленерго» (XLSX-переліки підчерг; PDF на сайті лише дублює XLSX і не парситься).
2. **Еталонність і виправлення помилок:** Помилки в написанні вулиць чи населених пунктів з XLSX виправляються через словник нормалізації та звірку із зовнішніми геоданими, але з обов'язковим збереженням зв'язку із сирим записом першоджерела.
3. **Керованість (прапорець активності):** Кожна адреса має статус (`active` / `gone` / `excluded`), що дозволяє керувати її потраплянням у чистий файл.
4. **Періодична перевірка:** База є статичною для клієнта, але має механізм локального періодичного порівняння з новими XLSX обленерго через Планувальник завдань Windows.

## 🚀 Швидкий старт

```powershell
# Ручний запуск повного пайплайна (з перевіркою hoe.com.ua, OSM і Visicom)
.\.venv\Scripts\python.exe src\monitor.py --profile profiles\hromada.json

# Перезбірка з локального кешу без мережевих запитів
.\.venv\Scripts\python.exe src\monitor.py --skip-fetch --force-rebuild

# Запуск автотестів (72 тести)
.\.venv\Scripts\python.exe -m pytest -q

# Реєстрація щоденного запуску в Планувальнику Windows (07:30 і 19:30)
powershell -ExecutionPolicy Bypass -File scripts\register_task.ps1
```

Усі результати зберігаються локально в простих JSON-файлах у теці `output/` (без баз даних і серверів). Деталі по Visicom API — у [VISICOM_GUIDE.md](VISICOM_GUIDE.md).
