# Інструменти проекту

Перелік MCP-серверів, плагінів та локальних інструментів, запропонованих для реалізації та підтримки бази адрес.

---

## 1. Вже підключені MCP-сервери

- **`postgres-mcp-server`** — для прямої роботи з PostgreSQL / Supabase (імпорт та оновлення еталонної бази адрес для бекенду `SvitloSk`).
- **`github-mcp-server`** — для синхронізації, версіонування та публікації готових наборів даних у репозиторіях (`SvitloSk`, `Parser-SvitloSk 2`).

---

## 2. Локальні інструменти (Python / CLI)

- **Python** — основний інструмент для:
  - парсингу та звірки PDF-файлів АТ «Хмельницькобленерго»;
  - нормалізації, очищення та валідації адрес;
  - роботи з локальною базою (`SQLite` / `JSON`);
  - періодичної звірки назв вулиць і населених пунктів через безкоштовний **OpenStreetMap (Overpass API)**.

---

## 3. Опціональні плагіни (Marketplace)

Додаються за потреби на етапі інтеграції або поглибленої верифікації геоданих:

- **Supabase** (`antigravity-plugins-partners/plugin/supabase`) — офіційний плагін для керування базою даних, схемою та міграціями Supabase.
- **Google Maps Platform** (`antigravity-plugins-official/plugin/google_maps_platform`) — для геокодування та перевірки складних або спірних адрес, якщо можливостей OpenStreetMap буде недостатньо.
